# Artes das estampas HMZT

Uma pasta por estampa (coleção), com 4 PNG de fundo transparente e nomes exatos:

| Arquivo | Vai na |
|---|---|
| `frente_modelo01_escuro.png` | frente da camiseta **branca** |
| `verso_modelo01_escuro.png` | costas da camiseta **branca** |
| `frente_modelo02_claro.png` | frente da camiseta **preta** |
| `verso_modelo02_claro.png` | costas da camiseta **preta** |

Recomendado: PNG com no mínimo 2000 px no lado maior, sem margens transparentes sobrando.

Depois de salvar: `/hmzt-lookbook-magnific P02 <nome-da-pasta>` no Claude Code.
Fila: `magnific/<estampa>/<Pxx>/` · Imagens prontas: `lookbook/<estampa>/<Pxx>/{branca,preta}/`.
