# Fluxo de prompts — P01 — Oversized Suedine Peruano 300g

> Dossiê e ficha: pastas [`dossies/`](../dossies/) e [`catalogo/`](../catalogo/) · Método e configuração: [README](README.md)

**Cores disponíveis:** OFF (off-white), BGE/ARE (areia), CHU (chumbo) — conferir cartela no dossiê P04 — os prompts vêm na cor das fotos originais; para outra cor, troque só o termo de cor (indicado em cada foto)

**Ordem de geração:** gere a F1 primeiro. Quando aprovada, use-a como **imagem de referência** nas demais (mesmo rosto, mesma peça, mesma luz).

**Tatuagens (Modelo A):** para modelo sem tatuagem, apague do prompt o trecho `both forearms covered with dense full-sleeve tattoos (...)`.
